# Dashboard Spacing Blueprint

This document gives a quick visual layout guide for the dashboard and each panel.
All layouts are text-only previews to guide the design.

---

## Global Layout (Desktop)

```
+--------------------------------------------------------------+
| Top Bar (56-64px)                                            |
+--------------------------------------------------------------+
| Sidebar (18-20%) | Main Content (80-82%)                     |
|                  |                                           |
|                  |                                           |
|                  |                                           |
+--------------------------------------------------------------+
```

### Sidebar Tabs (Single-Task Focus)

```
+------------------+
| Dashboard         |
| Upload            |
| Transcript        |
| Summary           |
| MCQ               |
| Flashcards        |
| AI Chat           |
| Analytics         |
| Rewards           |
| Export PDF        |
+------------------+
```

### Global Layout (Mobile)

```
+---------------------------+
| Top Bar                   |
+---------------------------+
| Main Content              |
|                           |
|                           |
+---------------------------+
| Bottom Nav (optional)     |
+---------------------------+
```

## 1) Upload Panel

```
+--------------------------------------------------------------+
| Upload Panel                                                  |
+---------------------------+----------------------------------+
| Upload Card (60%)         | History + Status (40%)           |

+---------------------------+----------------------------------+
```
